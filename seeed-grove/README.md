## Seeed Studio XIAO ESP32C3

The Seeed Studio XIAO ESP32C3 is a tiny development board based on the Espressif 
ESP32C3 32-bit RISC-V CPU microcontroller with 400KB of SRAM and 4MB of onboard 
flash storage. Thanks to the onboard radio, it supports both WiFi and Bluetooth 
wireless communication.

https://tinygo.org/docs/reference/microcontrollers/featured/xiao-esp32c3/
